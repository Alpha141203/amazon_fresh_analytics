  Amazon Fresh Data Analytics

  Project Overview

This project analyzes Amazon Fresh business data to identify
sales trends, customer behavior, product performance, and
business insights using SQL, Python, Excel, and Power BI.

 🎯 Objectives

- Analyze overall sales performance
- Identify top-performing products
- Analyze customer purchasing behavior
- Identify sales trends
- Analyze product and category performance
- Generate actionable business insights
- Build an interactive Power BI dashboard

 🛠️ Tools & Technologies

- SQL
- Python
- Pandas
- Excel
- Power BI
- DAX
- Data Cleaning
- Data Visualization

 📂 Project Structure

- `data/` – Dataset files
- `sql/` – SQL queries and analysis
- `python/` – Python data analysis scripts
- `powerbi/` – Power BI dashboard
- `excel/` – Excel analysis
- `reports/` – Project documentation
- `screenshots/` – Dashboard previews
